Powerful Annotation Tools

Everything you need. Nothing you don't.

Step Arrow

Arrows with auto-incrementing numbered circles — perfect for step-by-step guides.

Step Rectangle

Numbered rectangles that auto-increment — highlight regions with ordered callouts.

Arrow Tool

Draw clean, directional arrows with elegant filled arrowheads to point out details.

Rectangle

Highlight regions with outlined rectangles to draw attention to specific areas.

Circle / Ellipse

Draw circles and ellipses by dragging a bounding box. Stroke only, no fill.

Line

Draw simple straight lines without arrowheads.

Dashed Line

Draw straight dashed lines to mark borders, guides and boundaries. Right next to Line.

Question Arrow

Arrows with a question mark circle to mark questionable areas.

Question Rectangle

Rectangles with a question mark circle to mark questionable areas.

Exclamation Arrow

Arrows with an exclamation badge at the start — highlight warnings and must-see details.

Exclamation Rectangle

Rectangles with an exclamation badge at the top-left — call out critical regions.

Text

Place free-floating labels on the canvas — click to add, edit inline, and drag to reposition.

ABC Arrow

Arrows with auto-incrementing letter labels (a, b, ..., z, aa, ab).

ABC Rectangle

Rectangles with auto-incrementing letter labels (a, b, ..., z, aa, ab).

Magnifier

Create circular zoom lenses on your screenshot with configurable zoom (1.5×–5×). Perfect for highlighting small details.

Color Picker

Choose any annotation color with a full-spectrum color wheel.

Line Width

Adjust stroke thickness from 2px to 15px for just the right emphasis.

Area Selection

Select exactly the area you want to capture — no more cropping afterwards.

Save & Copy

One click saves to Downloads and copies to clipboard simultaneously.

🛡️ How to check that your download really comes from us

Every FeatherShot release is built by GitHub Actions from the public source code. The files on GitHub and on our download mirror are exactly the same, so they have the same SHA-256 fingerprint. After each release, GitHub Actions also uploads every file to VirusTotal, where more than 60 antivirus engines check it. The results are added to the release notes.

Step 2: the fingerprint of your file

Run these commands one after the other. Each line has its own copy button.

Open PowerShell (Start menu, type PowerShell) and go to your Downloads folder:

cd $HOME\Downloads

Show the fingerprint of the file:

(Get-FileHash .\{file} -Algorithm SHA256).Hash

Or let PowerShell compare it for you. It prints True when the file is ours:

(Get-FileHash .\{file} -Algorithm SHA256).Hash -eq "{hash}"

Open Terminal (Spotlight, type Terminal) and go to your Downloads folder:

cd ~/Downloads

Show the fingerprint of the file:

shasum -a 256 {file}

Or let Terminal compare it for you. It prints the file: OK when the file is ours:

echo "{hash} {file}" | shasum -a 256 -c

Open a terminal and go to your Downloads folder:

cd ~/Downloads

Show the fingerprint of the file:

sha256sum {file}

Or let the terminal compare it for you. It prints the file: OK when the file is ours:

echo "{hash} {file}" | sha256sum -c

If the two fingerprints are different, do not open the file. Delete it and download it again from this page.

Step 3 (optional): proof that GitHub built it from our code

From version 1.3.49 on, GitHub signs every release file with a build attestation. It proves that the file was built by the FeatherShot workflow in github.com/KurtStevenK/FeatherShot and was not changed afterwards, whether you downloaded it from GitHub or from our mirror.

Windows: install the GitHub CLI:

winget install --id GitHub.cli

macOS: install the GitHub CLI:

brew install gh

Debian or Ubuntu: install the GitHub CLI:

sudo apt install gh

Sign in to GitHub once (a free account is enough):

gh auth login

In your Downloads folder, check the file. It prints Verification succeeded! when GitHub built it from our code:

gh attestation verify {file} --repo KurtStevenK/FeatherShot

Step 4 (optional): look it up on VirusTotal yourself

Open virustotal.com, choose Search and paste the fingerprint from step 1. You see the scan results for our file without uploading anything.
