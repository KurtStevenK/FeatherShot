Short description

FeatherShot is a fast, native screenshot annotation tool with arrows, numbered steps, callouts, and magnifier lenses — free and open source for macOS, Windows, and Linux.

Long description

FeatherShot helps you capture a region of the screen and annotate it with professional tools: step arrows, numbered rectangles, text labels, question and exclamation callouts, ABC sequences, magnifier lenses, and flexible colors and stroke widths. It is lightweight, menu-bar friendly on macOS, and ships without subscriptions or cloud lock-in. Builds are available for macOS (native Swift), Windows and Linux (Electron), plus a Chrome extension for in-browser capture.
