Support

FeatherShot is free and open source. This page answers the most common questions about the app on macOS, Windows, Linux, and the Chrome extension.

Get help

Report a bug, request a feature, or ask a question on GitHub Issues. When you report a problem, include your FeatherShot version (shown in the menu) and your macOS, Windows, or Linux version. On Windows and Linux, the tray menu's Show Log File opens a log you can attach to the report.

Screen Recording permission (macOS)

FeatherShot needs Screen Recording permission to capture your screen. If a capture comes back empty or the selection does not appear, open System Settings → Privacy & Security → Screen Recording, turn FeatherShot on, and start the capture again. macOS may ask you to quit and reopen FeatherShot after you change this setting.

Downloads access (macOS)

Save & Copy writes a timestamped PNG to your Downloads folder. macOS asks for permission the first time. If you declined, allow FeatherShot under System Settings → Privacy & Security → Files and Folders. Copying to the clipboard works either way.

Where are my screenshots?

Saved screenshots are in your Downloads folder with a timestamp in the file name. Copies go to the clipboard, so you can paste them straight into another app. FeatherShot does not keep a copy on our servers, and it does not upload your screenshots anywhere.

Keyboard shortcuts

Every annotation tool has a shortcut that is shown in its tooltip (keys 1 to 0, -, =, T and M). ⌘Z (Ctrl+Z on Windows and Linux) undoes the last change, and ⌘S (Ctrl+S) saves and copies the screenshot. ⌘+, ⌘− and ⌘0 zoom in, zoom out, and show the screenshot at its original size. ⌘9 fits it to the window.

Updates

The Mac App Store and TestFlight builds are updated by Apple. Downloads from GitHub and this website can check for a newer version from the menu. Each release is listed in the changelog.

Privacy

FeatherShot has no accounts and does not send your screenshots anywhere. Read the full privacy policy.
